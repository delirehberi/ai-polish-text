## Reporting a Vulnerability

Security and privacy are foundational pillars of **LLM Text Polisher**.

If you discover a security vulnerability or potential credential leak:
- **Do NOT open a public GitHub issue.**
- Please report it directly to Emre Yılmaz via email at: `delirehberi@emre.xyz` or on Nostr at `https://nostr.emre.xyz`.
- Include detailed steps to reproduce the issue.

We will acknowledge receipt within 48 hours and work with you on a swift fix and disclosure timeline.
